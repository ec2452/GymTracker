# GymTracker
Sustav za praćenje napretka u teretani je ASP.NET Core MVC aplikacija namijenjena upravljanju članovima teretane, trening planovima, vježbama, mjerenjima i osobnim ciljevima. Aplikacija uključuje MVC sučelje, REST API, autentifikaciju i autorizaciju te rolu Admin, Trener i Korisnik.
Tehnologije: ASP.NET Core 8, MVC, Razor Pages, Entity Framework Core, SQL Server, ASP.NET Identity, JWT Bearer authentication i Google OAuth.
Glavne mogućnosti:
Evidencija korisnika i trenera
Upravljanje vježbama i planovima treninga
Praćenje treninga, mjerenja i ciljeva
Registracija i prijava korisnika
Kontrola pristupa pomoću uloga
REST API s JWT autentifikacijom
Serilog zapisnik i praćenje HTTP zahtjeva
MCP alati za programski pristup
Jedinično i Playwright end-to-end testiranje
